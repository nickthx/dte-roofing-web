## Component Inventory

### New Components

#### 1. ServiceAreaMap

- **File:** `src/components/ServiceAreaMap.tsx`
- **Purpose:** SVG-based visual map of 13 Central Ohio service areas for the /locations hub page
- **Placement:** Between hero section and city grid section on Locations.tsx
- **Dimensions:** `viewBox="0 0 100 80"`, `max-w-2xl mx-auto`, responsive width
- **Container:** White background, rounded-xl, border-2 border-gray-200, p-6
- **Section wrapper:** py-12 bg-white (lighter than adjacent sections)
- **Section heading:** "Our Service Area" -- text-2xl font-bold text-charcoal-900, centered
- **Section subheading:** "Serving 13 communities across Central Ohio" -- text-charcoal-600, centered

**Interaction contract:**
- Each city dot is wrapped in a `<Link to="/locations/{slug}">` for navigation
- City dots use `cursor-pointer` and `transition-colors` for hover feedback
- Hover changes dot fill from `primary-700` to `primary-500`
- No JavaScript interactivity beyond React Router link behavior
- No tooltip, no popover, no animation beyond color transition

**Accessibility contract:**
- SVG element: `role="img"` and `aria-label="Map of DTE Roofing service areas across 13 Central Ohio cities"`
- SVG contains `<title>DTE Roofing Service Area Map</title>` as first child
- City labels rendered as `<text>` elements (not images) for screen reader access
- Each city link inherits accessible name from city text label

**Data source:** `LOCATIONS` array from `src/data/locations.ts` for city names and slugs. City positions are a static `CITY_POSITIONS` record mapping slug to `{ x: number; y: number }` within the component file.

#### 2. No other new components

Service-to-location cross-links (LINK-04) are inline `<Link>` additions to existing service page JSX, not a standalone component.

### Modified Components

#### Locations.tsx

- Insert ServiceAreaMap section between hero (section 1) and city grid (section 2)
- No other structural changes to existing sections

#### Service Pages (up to 4 pages)

Pages needing additional inline location links (those with 0-1 existing links):
- `RoofInstallation.tsx` -- add links to New Albany, Westerville, Worthington
- `RoofInspection.tsx` -- add links to Delaware, Powell, Upper Arlington
- `PreventativeMaintenance.tsx` -- add links to Worthington, Dublin, Reynoldsburg
- `GutterServices.tsx` -- add links to Westerville, New Albany, Gahanna

Pages with 2+ existing links (RoofRepair, RoofReplacement, RoofMaintenance, EmergencyServices, StormDamage, CommercialRoofing, Gutters, Siding) already satisfy LINK-04 and require no changes.

**Link insertion rules:**
1. Convert existing plain-text city names to `<Link>` elements (same visible text, now clickable)
2. Use exact existing className: `"text-primary-700 hover:text-primary-800 font-semibold underline decoration-2 underline-offset-2"`
3. Do NOT modify any surrounding paragraph text
4. Do NOT add new sentences or paragraphs
