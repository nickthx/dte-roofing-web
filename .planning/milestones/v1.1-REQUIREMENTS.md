# Requirements: DTE Roofing Website

**Defined:** 2026-03-17
**Core Value:** Generate qualified roofing leads through professional presentation and trust

## v1.1 Requirements

Requirements for milestone v1.1 — Home page carousel. Each maps to roadmap phases.

### Carousel

- [x] **CARO-01**: User sees a smooth, auto-advancing image carousel in the "Our Recent Work" section
- [x] **CARO-02**: User can manually navigate between images (prev/next arrows)
- [x] **CARO-03**: Carousel displays project photos from existing `/public/images/` assets
- [x] **CARO-04**: Carousel is responsive and looks clean on mobile, tablet, and desktop
- [x] **CARO-05**: Carousel visually integrates with the Home page design (colors, spacing, typography)
- [x] **CARO-06**: User can see project title/location overlaid on each carousel image
