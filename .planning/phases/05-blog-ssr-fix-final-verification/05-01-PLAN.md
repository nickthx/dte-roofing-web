# Plan 05-01: Fix /blog SSR empty title and h1

<objective>
Fix the root cause of /blog shipping empty `<title>` and empty `<h1>` in prerendered HTML. The bug is a JSX rendering order issue: Blog.tsx has an `if (loading) return <Spinner/>` early return BEFORE `<SEO>` and `<h1>`, so during synchronous `renderToString` prerendering (where `useEffect` never fires and `loading` stays `true`), the component early-returns the spinner with no metadata. The fix moves `<SEO>` and the hero section above the loading conditional, and replaces the 166-char duplicate title with a proper blog-specific title. BlogPost.tsx gets the same structural fix with a static fallback.
</objective>

<action>
Edit `src/pages/BlogPost.tsx` to add a static fallback SEO component above the loading and not-found guards:

1. **Add a static `<SEO>` immediately inside the component function, before the `if (loading)` check at line 56.** Insert a wrapper that renders the fallback SEO and then conditionally renders the rest:

Replace the `if (loading)` early return (lines 56-62) and `if (!post)` early return (lines 64-77) with inline conditionals inside a single return block. The new structure:

```tsx
export default function BlogPostPage() {
  // ... existing state and useEffect (lines 22-46 unchanged) ...
  // ... getReadingTime helper (lines 49-53 unchanged) ...

  // Static fallback title for SPA shell (overridden by dynamic title when post loads)
  const pageTitle = post ? `${post.title} | DTE Roofing Blog` : 'DTE Roofing Blog | Central Ohio Roofing Tips';
  const pageDescription = post ? post.excerpt : 'Roofing tips, maintenance guides, and expert advice for Central Ohio homeowners from DTE Roofing.';
  const pageCanonical = post ? `https://www.dteroofingllc.com/blog/${post.slug}` : undefined;
  const pageKeywords = post ? (post.tags?.join(', ') || 'roofing, Columbus, Ohio') : 'roofing blog, Columbus, Ohio, roof tips';

  if (loading) {
    return (
      <div className="min-h-screen bg-white">
        <SEO
          title={pageTitle}
          description={pageDescription}
          keywords={pageKeywords}
          canonical={pageCanonical}
        />
        <div className="flex items-center justify-center min-h-[60vh]">
          <div className="animate-spin rounded-full h-12 w-12 border-b-2 border-primary-700"></div>
        </div>
      </div>
    );
  }

  if (!post) {
    return (
      <div className="min-h-screen bg-white">
        <SEO
          title={pageTitle}
          description={pageDescription}
          keywords={pageKeywords}
        />
        <div className="flex flex-col items-center justify-center min-h-[60vh]">
          <h1 className="text-3xl font-bold text-charcoal-900 mb-4">Post Not Found</h1>
          <p className="text-charcoal-600 mb-8">The blog post you're looking for doesn't exist.</p>
          <Link
            to="/blog"
            className="bg-primary-700 text-white px-6 py-3 rounded-lg hover:bg-primary-800 transition-all font-semibold inline-flex items-center"
          >
            <ArrowLeft className="w-4 h-4 mr-2" /> Back to Blog
          </Link>
        </div>
      </div>
    );
  }

  // ... rest of the component unchanged (the existing return with dynamic SEO) ...
```

This ensures every code path renders `<SEO>`. The `/blog/:slug` route is NOT prerendered (dynamic, SPA fallback), but this gives the SPA shell a reasonable fallback title.
</action>
