## Tasks

### Task 1: Audit each location page and record current metadata — type="auto"

For each of the 13 files, read and capture:
- Current `<SEO title={...}>` string and line number
- Current `<SEO description={...}>` string and line number
- Current hero `<h1>` string and line number (this will be rewritten)
- Current primary services `<h2>` string and line number (this will be rewritten)
- Any NAP strings in the description (preserve verbatim)

Record in a working table inside `04-COPY-DRAFTS.md` under an "Audit" section.

**Done when:** Audit section lists all 13 pages with current values + exact line numbers.

### Task 2: Map per-city secondary services from GBP research — type="auto"

Read `.planning/research/v1.1-gbp-competitors.md`. For each of the 13 cities, extract the top 3-5 secondary services competitors list in GBP (beyond the primary "Roof Repair / Replacement"). If the research file only covers the 5 representative cities from Phase 1 (Columbus, Hilliard, Dublin, Westerville, Delaware), use those verbatim and apply the nearest-neighbor city's services for the remaining 8 (noting the substitution in the drafts).

Record the per-city mapping as a table in `04-COPY-DRAFTS.md` under "Secondary Service Mapping".

**Done when:** All 13 cities have a secondary-services list documented, each tagged either `(from GBP research)` or `(inherited from {nearest city})`.

### Task 3: Draft descriptions, H1, and H2 for all 13 pages — type="auto"

For each page, draft:
- **Meta description** (140-200 chars): mention primary service + city + a differentiator (owner-involved, detail-first, free inspections). Include "614-971-6028" only where it fits within the char budget. No "BEST" / "#1" / "most trusted" / "highest-rated" superlatives (META-05). NAP addresses preserved verbatim where referenced.
- **H1**: `Primary Service + City` format per HEAD-01. Example: "Roof Repair & Replacement in Columbus, OH" (overrides the existing brand-voice H1 like "Columbus's Go-To Roofer — Right Here in Your Backyard"). User has pre-authorized this override in the roadmap.
- **H2 (primary services section)**: `Secondary + Services in {City}` format per HEAD-03, listing 3-5 secondary services from Task 2's mapping. Example: "Storm Damage, Gutters, Siding & Emergency Roofing in Columbus".

Each entry in the drafts file must include:
1. Page # and route
2. File + line numbers to edit (from Task 1 audit)
3. Current → proposed (diff format) for description, H1, H2
4. Character count for descriptions
5. Note whether the existing title is being kept (default) or changed

**Done when:** `04-COPY-DRAFTS.md` contains 13 complete entries, each with char-counted descriptions and line-number pointers.

- [ ] H1 matches `Primary Service + City` format
- [ ] H2 matches `Secondary + Services in City` format
- [ ] NAP preserved verbatim in any description that references it
- [ ] 13 unique descriptions (no duplicates)
- [ ] 13 unique H1s (no duplicates)
- [ ] 13 unique H2s (no duplicates)

Record checklist results at the bottom of `04-COPY-DRAFTS.md`. Fix any failures before proceeding.

**Done when:** All 13 pages pass all 9 checks.

### Task 5: Checkpoint — user approval of draft packet — type="checkpoint:human-verify" gate="blocking"

**What built:** `04-COPY-DRAFTS.md` with 13 fully drafted location metadata entries, per-city GBP service mappings, and self-review checklist results.

**How to verify:**
1. Open `.planning/phases/04-location-descriptions-h1-h2/04-COPY-DRAFTS.md`
2. Review the 13 drafted description/H1/H2 sets

**Resume signal:** Type "approved" to freeze the packet, OR list specific revisions needed (e.g., "Columbus H1 should be X, Dublin description too long"), OR "also rewrite titles" to expand scope.
