## Tech Debt (4 items across 2 phases)

### Phase 1: Data Architecture & Schema Fixes

1. **Hub page local locations array** — `src/pages/Locations.tsx` lines 7-86 maintains a local `locations` constant that duplicates `src/data/locations.ts`. Schema and map consume the SSOT, but the city card grid does not. Data currently matches but will diverge on future edits. (DATA-01 partial closure)

2. **Hub breadcrumb self-reference** — `src/components/SchemaMarkup.tsx` lines 205-217: when `type='hub'`, breadcrumb produces position 2 (`/locations`) and position 3 (`/locations`) pointing to the same URL. Google may ignore/truncate. Subpages work correctly. (SCHEMA-06 informational)

3. **Missing useEffect dependencies** — `src/components/SchemaMarkup.tsx` line 299: `locationName` and `pageDescription` absent from dependency array. No runtime impact (values are static per render) but will produce lint warnings with `react-hooks/exhaustive-deps`. (SCHEMA-08 lint risk)

4. **Unused export** — `getAllLocationSlugs()` exported from `src/data/locations.ts` but never imported anywhere. No runtime impact. (DATA-01 cleanup)
