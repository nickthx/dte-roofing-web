# Remove duplicate og:* / twitter:* tags from index.html shell

## Problem

The 2026-05-03 technical SEO audit found that every prerendered page ships TWO `og:url` tags:

1. Hardcoded in `index.html` (always `https://www.dteroofingllc.com/`)
2. Emitted by react-helmet-async via `SEO.tsx` (correct per-page value)

Same duplication for `og:image`, `og:type`, `twitter:image`. Caused by 260413-tb5 which added these as static fallbacks in `index.html` for non-JS bots — but the prerender script (`scripts/prerender.mjs`) already inlines the Helmet output into the static HTML, making the fallbacks both redundant and actively wrong (social scrapers may grab the first occurrence and link cards to the homepage).

Additionally: `twitter:site="@DTERoofing"` is a dead tag — DTE Roofing has no X/Twitter account.

## Scope

**Modify:**
- `index.html` — remove page-specific og:* / twitter:* tags (keep og:locale, og:site_name only)
- `src/components/SEO.tsx` — drop `twitterSite` prop, interface field, and `<meta name="twitter:site">` render

**Verify:**
- `npm run build` passes
- Prerendered output has exactly one `og:url` per page (the Helmet one)
- Prerendered output has zero `twitter:site` tags anywhere
- Spot-check `dist/locations/columbus/index.html` head visually

## Protected (do not touch)

- public/sitemap.xml, vercel.json, scripts/prerender.mjs, scripts/generate-sitemap.mjs, routes.config.mjs
- All page components and routing logic
- Roofle widget script tag and preconnect
- DEFAULT_OG_IMAGE / DEFAULT_OG_IMAGE_ALT constants in SEO.tsx
- All other Helmet-emitted og:* / twitter:* tags in SEO.tsx (only twitter:site is removed)

## Tags removed from index.html

- og:type, og:image, og:image:width, og:image:height, og:image:type, og:image:alt, og:url
- twitter:card, twitter:image, twitter:image:alt, twitter:site

## Tags kept in index.html

- og:locale (en_US), og:site_name (DTE Roofing)
- All non-OG meta (viewport, description, author, robots, etc.) and links/scripts unchanged
