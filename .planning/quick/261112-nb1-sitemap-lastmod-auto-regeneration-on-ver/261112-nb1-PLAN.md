**Loader rewrite (loadGoogleMaps)**
1. Add a module-level `let mapsLoadPromise: Promise<void> | null = null;` and a module-level constant callback name, e.g. `const MAPS_CALLBACK = '__dteServiceAreaMapInit';`. Do not touch `window` at module scope, because the component is SSR-prerendered.
2. Readiness check: a small helper `isMapsReady()` returns true when `window.google?.maps?.marker?.AdvancedMarkerElement` is defined. Do NOT use `window.google?.maps` alone. Under loading=async that object exists before the marker library does.
3. `loadGoogleMaps()` behaves as follows:
   - If API_KEY is missing, reject with the existing message.
   - If `isMapsReady()`, resolve immediately.
   - If `mapsLoadPromise` exists, return it.
   - Otherwise create and memoize the promise. Its executor first assigns `window[MAPS_CALLBACK]`, a function that resolves once `isMapsReady()` is true. If the marker library is somehow not ready yet but `google.maps.importLibrary` exists, it awaits `google.maps.importLibrary('marker')` and then resolves.
   - Existing-script guard: if `document.querySelector('script[src*="maps.googleapis.com"]')` already exists, do not append a new script. Because that script was not created with our callback, poll `isMapsReady()` every 100ms, up to 10s, and resolve, or reject on timeout. Do not wait on its `load` event, which fires too early under loading=async and never fires if the script already loaded.
   - Otherwise append a script with src `https://maps.googleapis.com/maps/api/js?key=${API_KEY}&loading=async&libraries=marker&callback=${MAPS_CALLBACK}`, plus `script.async = true`. Drop `defer`. `onerror` rejects with the existing message, calls `script.remove()` and resets `mapsLoadPromise = null`, so a later mount can really retry. Without the remove, the dead tag would trip the existing-script guard. The readiness-poll timeout also resets `mapsLoadPromise = null` before rejecting. NEVER resolve from `script.onload`.
4. Typing: `@types/google.maps` is absent and existing `google` references already produce pre-existing tsc errors, so do not add types or packages. For the callback assignment, use a narrow cast such as `(window as unknown as Record<string, unknown>)[MAPS_CALLBACK] = ...` and do not add other new `any`. The build (esbuild) is the gate.
