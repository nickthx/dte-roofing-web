- twitter:image mirrors the resolved og:image so the two platforms stay in sync without a second default chain.
- twitter:site is opt-in (no default in the component) so that existing call sites are unaffected; index.html provides the site-wide static fallback.

- Introduce a new default for twitter:site in the component (index.html handles that site-wide).
- Modify geo.placename, keywords, or canonical behavior.
