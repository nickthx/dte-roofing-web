<objective>
Move the hardcoded Google Maps browser API key out of `src/components/ServiceAreaMap.tsx` into a Vite environment variable (`VITE_GOOGLE_MAPS_API_KEY`). The component reads it via `import.meta.env`, degrades gracefully when the var is unset, and is backed by a gitignored `.env` (working key for local dev) plus a committed `.env.example` placeholder.

Purpose: The repo is public on GitHub. A hardcoded key in tracked source is exposed to anyone who clones it. Reading from an env var removes the literal from source. (Inlining a browser-restricted Maps key into the client bundle at build time is expected and acceptable — the security win is removing the plaintext literal from tracked source and enabling per-environment rotation.)
Output: Typed env access, an env-driven component with graceful degradation, `.env` (gitignored) + `.env.example` (committed), and a green `npm run build`.

Out of scope: Rotating the exposed key in Google Cloud Console (a separate user action), and pushing to remote (do NOT push).
</objective>
